## Common RTL Issues

### CSS Fixes Needed
```css
/* ❌ Bad - hardcoded directions */
.sidebar {
  left: 0;
  padding-left: 20px;
  margin-right: 10px;
}

/* ✅ Good - logical properties */
.sidebar {
  inset-inline-start: 0;
  padding-inline-start: 20px;
  margin-inline-end: 10px;
}
```

### Tailwind RTL Classes
```html
<!-- ✅ Use RTL-aware classes -->
<div class="ml-4 rtl:mr-4 rtl:ml-0">
<div class="text-left rtl:text-right">
<div class="pl-2 rtl:pr-2 rtl:pl-0">

<!-- Or use logical properties -->
<div class="ms-4">  <!-- margin-inline-start -->
<div class="ps-2">  <!-- padding-inline-start -->
<div class="text-start">
```

## Translation Verification

### Check for Missing Keys
```bash
# Compare ar.json and en.json keys
diff <(jq -r 'keys[]' messages/ar.json | sort) \
     <(jq -r 'keys[]' messages/en.json | sort)
```

### Check for Hardcoded Text
```bash
# Find hardcoded strings in components
grep -r '"[A-Za-z].*"' src/components/ --include="*.tsx" | grep -v "import\|className"
```
